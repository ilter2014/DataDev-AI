DATADEV AI - WINDOWS VDS KURULUMU
==================================

Bu kurulum Windows Server 2022 içindir. Linux/Docker gerekmez.

1) Projeyi VDS'ye kopyala veya GitHub'dan indir:
   git clone https://github.com/ilter2014/DataDev-AI.git DataDevAI
   cd DataDevAI

2) Python 3.11 veya üstünü kur. PowerShell'i proje klasöründe aç:
   py -3.11 -m venv .venv
   .\.venv\Scripts\python.exe -m pip install --upgrade pip
   .\.venv\Scripts\python.exe -m pip install torch

   CPU PyTorch kurulumu uzun sürebilir. Kurulum sonunda test:
   .\.venv\Scripts\python.exe -c "import torch; print(torch.__version__)"

3) datadev_gpt_v5_model.pt ve datadev_gpt_v5.py dosyaları proje klasöründe olmalı.
   Model yoksa koordinatörü başlatma; önce geçerli v5 checkpoint'i kopyala.

4) PowerShell'de iki farklı güçlü anahtar üret ve sadece bu PowerShell oturumunda tanımla:
   $bytes = New-Object byte[] 48
   [Security.Cryptography.RandomNumberGenerator]::Fill($bytes)
   $env:DATADEV_CLUSTER_ADMIN_TOKEN = [Convert]::ToBase64String($bytes)
   $bytes = New-Object byte[] 48
   [Security.Cryptography.RandomNumberGenerator]::Fill($bytes)
   $env:DATADEV_CLUSTER_WORKER_TOKEN = [Convert]::ToBase64String($bytes)
   $env:DATADEV_CLUSTER_HOST = "127.0.0.1"
   $env:DATADEV_CLUSTER_PORT = "8765"

   Anahtarları paylaşırken yalnızca İlter ve Mert'e güvenli yoldan ilet.
   Anahtarları kaynak dosyalarına, GitHub'a veya herkese açık sohbetlere koyma.
   Yönetici anahtarı sadece yönetim uygulamasında; worker anahtarı yalnızca worker istemcilerinde kullanılır.

5) Güvenli ağ:
   Koordinatörü doğrudan herkese açık HTTP ile internete açma.
   VDS, İlter PC ve Mert PC'ye Tailscale kurup aynı özel ağa bağla.
   VDS üzerinde Tailscale Serve kullanarak localhost:8765 için HTTPS adresi oluştur.
   Örnek komut (kurulu Tailscale sürümünün yardımını kontrol et):
   tailscale serve --bg 8765
   Komutun verdiği HTTPS/MagicDNS adresini kaydet.
   İşçi bilgisayarlar yalnızca bu HTTPS adresini kullanmalı. Windows güvenlik duvarında
   8765 portunu genel ağa açma; koordinatör localhost'a bağlı kalır.

6) Koordinatörü başlat:
   .\.venv\Scripts\python.exe -X utf8 datadev_cluster_server.py --host 127.0.0.1 --port 8765

7) Aynı VDS'de ikinci PowerShell penceresinde yerel işçiyi başlat:
   $env:DATADEV_CLUSTER_WORKER_TOKEN = "VDS'de oluşturduğun worker anahtarı"
   .\.venv\Scripts\python.exe -X utf8 datadev_cluster_worker.py --server http://127.0.0.1:8765 --worker-id vds-worker

8) İlter ve Mert bilgisayarlarında aynı proje kodunu ve PyTorch CPU kur:
   py -3.11 -m venv .venv
   .\.venv\Scripts\python.exe -m pip install --upgrade pip
   .\.venv\Scripts\python.exe -m pip install torch

   PowerShell'de:
   $env:DATADEV_CLUSTER_URL = "VDS'nin Tailscale HTTPS adresi"
   $env:DATADEV_CLUSTER_WORKER_TOKEN = "VDS'deki worker anahtarı"
   .\.venv\Scripts\python.exe -X utf8 datadev_cluster_worker.py --server $env:DATADEV_CLUSTER_URL --worker-id ilter-pc

   Mert kendi bilgisayarında worker kimliğini mert-pc yapar.
   Her iki bilgisayarda da worker penceresi açık kalmalı.

9) İlter'in PC'sinde yönetim uygulaması:
   $env:DATADEV_CLUSTER_URL = "VDS'nin Tailscale HTTPS adresi"
   $env:DATADEV_CLUSTER_ADMIN_TOKEN = "VDS'deki yönetici anahtarı"
   Çift tıklama: DataDev AI - Küme Yönetim Merkezi.bat

NASIL ÇALIŞIR?
--------------
- Yönetim merkezi VDS'ye eğitim turu ve sabit eğitim ayarları yollar.
- VDS, görevleri kayıtlı işçi kimliklerine ayırır.
- PC'ler kendilerine atanmış metin parçasında yerel eğitim yapar ve model ağırlıklarını geri gönderir.
- Yönetici tüm görevler tamamlanınca birleştirmeyi başlatır.
- VDS, tensor şekillerini doğrular ve doğrulama kaybı kötüleşirse modeli reddeder.
- Kabul edilirse v5 checkpoint yedeklenir ve sürüm artırılır; işçiler yeni sürümü sonraki yoklamada indirir.

ÖNEMLİ SINIRLAR
---------------
- Bu ilk prototipte FedAvg ile ağırlık birleştirme var; bu, üç PC'nin RAM/CPU'sunu tek bir dev bilgisayar gibi birleştirmez.
- Model 500K civarı parametreli küçük bir karakter-GPT'dir; parametre artışı tek başına kaliteli sohbet garantisi değildir.
- Eğitim görevleri sabit ve sınırlıdır; koordinatör worker bilgisayarlarında rastgele CMD/PowerShell komutu çalıştırmaz.
- Ağ ve VDS kurulumu henüz uzaktan yapılmış sayılmaz. Tailscale, Python/PyTorch, anahtarlar ve model dosyası VDS'de ayrıca hazırlanmalıdır.
