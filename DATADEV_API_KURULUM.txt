DATADEV AI API — CURRENT SETUP
==============================

Start with: DataDev AI API.bat
The API loads datadev_gpt_v5_model.pt and uses datadev_gpt_v5.py.
The API is a local prototype; keep it bound to localhost unless you have configured authentication and network protections.

Python packages: install the requirements used by the v5 model (PyTorch).
Never commit groq_api_key.txt, .env, access tokens, or other secrets.
