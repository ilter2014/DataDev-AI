DATADEV GPT V4 + GROK DENETÇİSİ KURULUMU

1) https://console.x.ai/ adresinden xAI API erişimi oluştur ve bir API anahtarı al. API kullanımı ücretli olabilir; hesabındaki fiyatlandırmayı kontrol et.
2) Anahtarı DataDevAI klasöründeki grok_api_key.txt dosyasına tek satır olarak yapıştır.
3) Bu dosyayı kimseyle paylaşma ve internete/GitHub'a yükleme. Anahtar hesabına erişim sağlar.
4) DataDev GPT v4 - Grok.bat dosyasını çalıştır.
5) DataDev önce yerel taslak cevap oluşturur. Grok taslağı inceler ve KEEP (bunu kullan) veya REPLACE (bunu değiştir) kararı verir. REPLACE ise Grok'un düzelttiği cevap gösterilir.

Grok'a her soru ve DataDev'in taslak cevabı xAI API üzerinden gönderilir. Gizli kişisel bilgileri yazma.

API anahtarı yoksa uygulama yalnızca yerel taslağı gösterir; Grok denetimi yapılmış gibi davranmaz.

İsteğe bağlı: XAI_MODEL ortam değişkeni ile model adını değiştirebilirsin. Varsayılan: grok-4.7.
